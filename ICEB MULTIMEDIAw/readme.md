# iCEB Multimedia Website

A modern, responsive website developed for **iCEB Multimedia**, a creative multimedia agency specializing in:

- Professional Photography
- Graphic Design
- Advertising Solutions

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

## Pages

- Home
- About
- Services
- Portfolio
- Contact
- 404 Error Page

## Features

- Responsive Design
- Sticky Navigation
- Portfolio Gallery
- Contact Form
- Smooth Scrolling
- Animated Counters
- Scroll Animations
- WhatsApp Floating Button
- Back-to-Top Button
